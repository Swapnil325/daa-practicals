# String Matching (DAA Mini Project)

This mini-project provides a Java implementation of string matching using two algorithms:

- Naive (brute-force) string matching
- Rabin-Karp algorithm (rolling hash)

Files:
- mini-projects/string-matching/StringMatching.java — Java source

Compile and run:

javac mini-projects/string-matching/StringMatching.java
java -cp . mini-projects.string-matching.StringMatching

Or from the project root:

cd mini-projects/string-matching
javac StringMatching.java
java StringMatching

The program reads a text and a pattern from stdin and prints match positions for both algorithms.
