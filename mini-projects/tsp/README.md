# TSP Mini Project

This mini-project compares two approaches for solving the Travelling Salesman Problem (TSP):

- Exact brute-force permutation search
- Nearest Neighbour heuristic

Files:
- mini-projects/tsp/TSPComparison.java — Java source

Compile and run:

javac mini-projects/tsp/TSPComparison.java
java -cp mini-projects/tsp TSPComparison

The program uses a sample 4-city distance matrix and prints the best tour and total cost.
